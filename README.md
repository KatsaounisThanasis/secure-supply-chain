# Secure Software Supply Chain Lab

A production-oriented DevSecOps laboratory demonstrating Software Supply Chain Security best practices (SLSA, SBOM, Container Signing).

## 🎯 Goal
Implement a Zero-Trust CI/CD pipeline that ensures artifact integrity and security from code to deployment.

## 📦 Core Features (Roadmap)
- [ ] **SBOM Generation:** CycloneDX/SPDX generation.
- [ ] **Vulnerability Scanning:** Static (SAST) and Container scanning with Trivy.
- [ ] **Image Signing:** Digital signatures using Cosign/Sigstore.
- [ ] **Policy Enforcement:** Reject unsigned or vulnerable images.
- [ ] **Provenance:** SLSA attestations.
